# Подготовка к сборке Android приложения (APK)

Данный проект уже содержит все необходимые базовые компоненты для сборки Android-приложения (APK) с помощью фреймворка Capacitor.

## Важно: Ограничения API

Приложение использует серверные (API) роуты Next.js (например, `/api/tinvest/route.ts`), которые выступают прокси-сервером для обхода CORS политик T-Bank Invest API. 
Эти серверные роуты **не могут** работать локально внутри статического APK-файла.

Поэтому у вас есть два пути для сборки APK:

### Вариант 1: Обертка развернутого (Hosted) приложения (Рекомендуется)

В этом случае APK будет выступать "браузером" без адресной строки, который сразу загружает ваш сайт. Все функции будут работать идеально.

1. Опубликуйте ваше приложение (кнопка Deploy / Share в AI Studio). 
2. Получите URL (например, `https://ais-pre-...run.app`).
3. Откройте файл `capacitor.config.ts` и раскомментируйте секцию `server`:
   ```typescript
   server: {
     url: 'ВАШ_РАЗВЕРНУТЫЙ_URL',
     cleartext: true
   }
   ```
4. Выполните инициализацию платформы:
   ```bash
   npx cap add android
   npx cap sync android
   ```
5. Откройте проект в Android Studio (или используйте CLI):
   ```bash
   npx cap open android
   ```
   Соберите APK (Build -> Build Bundle(s) / APK(s) -> Build APK(s)).

### Вариант 2: Полностью статическая сборка (Если перепишете API)

Если вы решите перенести логику `/api/tinvest` на отдельный бэкенд, либо выполнять запросы напрямую из клиента (потребует решения проблем с CORS на стороне T-Bank), то можно собрать полностью автономный APK:

1. В файле `next.config.ts` добавьте `output: 'export'`.
2. Выполните сборку проекта:
   ```bash
   npm run build
   ```
   (Будет создана папка `out`).
3. Добавьте платформу и скопируйте файлы:
   ```bash
   npx cap add android
   npx cap sync android
   ```
4. Откройте проект в Android Studio:
   ```bash
   npx cap open android
   ```
   Соберите APK.
