# Руководство по установке и сборке APK для Android (со смартфона)

В проекте настроены **два самых простых способа** превратить терминал в Android-приложение, даже если у вас нет доступа к компьютеру:

---

## Вариант 1: Мгновенная установка через Chrome (PWA) — Без ожидания сборки

Это самый быстрый способ (занимает 5 секунд прямо сейчас):

1. Откройте приложение в браузере **Google Chrome** на вашем Android-смартфоне.
2. Нажмите на меню браузера **⋮** (три вертикальные точки в верхнем правом углу).
3. Выберите пункт **«Установить приложение»** (или **«Добавить на главный экран»**).
4. Подтвердите установку.

📱 **Результат:** 
На рабочем столе вашего смартфона появится полноценная иконка **FC MOEX**. Приложение будет открываться на полный экран (без адресной строки браузера), сохранять все введенные позиции в памяти устройства, работать с тактильной отдачей и иметь быстрый доступ ко всем расчетам Мосбиржи.

---

## Вариант 2: Автоматическая сборка APK-файла через GitHub Actions (Без ПК)

В репозиторий уже добавлен автоматический сценарий сборки `.github/workflows/android.yml`.

### Шаги для получения APK:

1. **Экспорт в GitHub:**
   - В интерфейсе Google AI Studio в верхнем правом углу нажмите на меню настроек/экспорта (или кнопку **Share / Export**) и выберите **Export to GitHub** (Экспорт в GitHub).
   - Подтвердите создание репозитория в вашем аккаунте GitHub.

2. **Автоматическая сборка (1-2 минуты):**
   - Как только репозиторий будет создан, встроенный робот **GitHub Actions** автоматически запустит компиляцию Android APK на серверах GitHub.
   - Вы можете отслеживать прогресс во вкладке **Actions** в вашем репозитории.

3. **Скачивание APK на смартфон:**
   - Откройте ваш репозиторий в браузере на телефоне.
   - Перейдите в раздел **Releases** (Релизы) на главной странице репозитория.
   - Нажмите на файл **`FC-MOEX-Calculator.apk`** — он мгновенно скачается на ваш телефон.
   - Откройте скачанный файл и нажмите **Установить** (если система запросит разрешение на установку из браузера — подтвердите «Разрешить для этого источника»).

Готово! У вас на смартфоне будет установлен полноценный нативный APK-файл.
