# Сборка Android-приложения

Проект полностью настроен для компиляции в APK файл через Android Studio.

## Как собрать APK приложение

Так как наше приложение использует Next.js серверные функции (API Proxy на стороне сервера), лучший и самый надежный способ для работы мобильного приложения — использовать Capacitor Capacitor как "WebView". В этом случае приложение на телефоне будет открывать ваш развернутый в интернете сайт, но выглядеть и работать как полноценное мобильное приложение без рамок браузера.

1. **Разверните приложение**
   Откройте настройки AI Studio или нажмите кнопку *Share*, чтобы получить публичную ссылку на ваше приложение (например `https://ais-pre-....run.app`).

2. **Загрузите проект на ваш компьютер**
   Скачайте и распакуйте архив с GitHub на свой ПК.

3. **Установите зависимости**
   Убедитесь, что у вас установлен Node.js. Откройте терминал внутри папки проекта и выполните команду:
   ```bash
   npm install
   ```

4. **Настройте URL в Capacitor**
   Откройте файл `capacitor.config.ts` в любом текстовом редакторе. Сейчас он выглядит так:
   ```typescript
   import { CapacitorConfig } from '@capacitor/cli';

   const config: CapacitorConfig = {
     appId: 'com.moex.vmcalc',
     appName: 'F.Calc',
     webDir: 'out'
   };

   export default config;
   ```
   
   Вам нужно добавить в него секцию `server`, вписав публичную ссылку на ваш сайт:
   ```typescript
   import { CapacitorConfig } from '@capacitor/cli';

   const config: CapacitorConfig = {
     appId: 'com.moex.vmcalc',
     appName: 'F.Calc',
     webDir: 'out',
     server: {
       url: 'ВСТАВЬТЕ_СЮДА_ПУБЛИЧНУЮ_ССЫЛКУ_НА_РАБОЧЕЕ_ПРИЛОЖЕНИЕ',
       cleartext: true
     }
   };

   export default config;
   ```

5. **Обновите настройки Android**
   После того как вы прописали URL, выполните команду:
   ```bash
   npx cap sync android
   ```

6. **Соберите APK файл**
   - Убедитесь, что у вас установлена программа **Android Studio**.
   - В терминале выполните команду, которая сама откроет этот проект в Android Studio:
     ```bash
     npx cap open android
     ```
   - В верхнем меню Android Studio выберите **Build > Build Bundle(s) / APK(s) > Build APK(s)**
   - Подождите 1-2 минуты. В правом нижнем углу появится уведомление с кнопкой `locate` (Найти). Нажмите её, и откроется папка с файлом `app-debug.apk`.
   
Готово! Файл `.apk` можно скинуть на свой Android смартфон и установить (потребуется разрешить установку из неизвестных источников). На домашнем экране появится иконка и чистое приложение на полный экран под названием "F.Calc".
